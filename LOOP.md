# LOOP v2 — RWS: инструкция и публикация

Ревизия после независимой проверки ChatGPT (21.10.2026). Изменения: два независимых результата,
право вето, доказательная таблица, статусы только PASS / FAIL / BLOCKED / NOT VERIFIED,
сценарии разведены, правила группы стали блокирующим воротом.

## Решение по главному вопросу

Инструкция покрывает **оба сценария отдельными ветками**:

- **A. Первая подача** (основная ветка): вход → поиск услуги → мастер 11 шагов → подпись.
- **B. Заявление уже подано** (ветка разбора): экран блокировки → `Uzupełnienie/korekta` →
  `Koryguj` → те же шаги с заполненными полями.

Скриншоты снимались на аккаунте, где заявление за 11/2026 уже есть. Значит **все кадры
мастера относятся к ветке B** и не могут доказывать ветку A. В инструкции каждый кадр это
помечает. Ветка A остаётся NOT VERIFIED на шагах 4–11 до съёмки на чистом аккаунте.

## Два результата (не смешивать)

- **A. Инструкция** — текст и кадры проверены, визуальная приёмка пройдена.
- **B. Коммуникация в группе** — сценарий вопроса и ответа одобрен Ольгой.

## Ворота

**G1 Текст.** Каждый существенный факт имеет: формулировку, официальный URL, дату проверки,
поддерживающий фрагмент, место использования. Нет подтверждения — NOT VERIFIED.

**G2 Кадры.** Матрица шагов 1–11 с колонкой `wizard_step`, файлом, ожидаемым состоянием,
статусом и причиной отсутствия. Финальные файлы (не исходники) проверены целиком; маскированные
области растеризованы необратимо. Оригиналы с данными плательщика не попадают ни в публичный
репозиторий, ни в историю коммитов, ни в доступные по ссылке материалы.

**G2b Приватность файлов.** Отдельный критерий от G2: маскированные области растеризованы необратимо, каждый финальный файл проверен целиком, оригиналы отсутствуют в публичном репозитории, в истории коммитов и по ссылкам. До прохождения — NO-GO на публичное использование кадров s02–s10 и n02.

**G3 Содержание.** Ольга подтвердила формулировки и тон.

**G4 Публикация.** Блокируется, если: ссылки запрещены правилами группы, нужен другой формат,
нет согласования с админами. Публикация отвечает реальному запросу человека; инсценировка
спонтанного вопроса и имитация независимой рекомендации запрещены.
