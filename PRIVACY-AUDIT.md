# Приватность: аудит и очистка публичной истории

## Что было не так

Первые кадры снимались до того, как маскировка была включена. В публичной истории
репозитория лежали оригиналы с открытыми данными:

- `ezus-02-katalog.png` — имя и NIP в шапке
- `ezus-04-tile-open.png` — имя и NIP в шапке
- `ezus-06-rws-step2.png` — имя, NIP, номер PESEL в полях
- `ezus-20-podsumowanie.png` — имя в шапке

Затронуты коммиты `700ac9e`, `91b0e5c`, `d043ec8`, `594f846`, `40e8145`.

## Что сделано

1. Четыре файла перекрыты чёрными прямоугольниками по координатам OCR (tesseract, conf ≥ 40),
   маска нанесена на пиксели, а не поверх текста в DOM.
2. Повторный OCR всех 22 кадров не находит ни имени, ни NIP, ни 11-значных чисел.
3. Публичная история пересобрана: один коммит `v2` содержит только очищенное дерево.
   Прежняя история сохранена локально в `/root/.hermes/state/zus-rws-loop-pre-scrub.bundle`,
   онлайн её больше нет.

## Как проверить

```bash
git clone https://github.com/indrad3v4/zus-rws-loop
cd zus-rws-loop
git rev-list --objects --all | awk '{print $1}' | sort -u | while read o; do
  t=$(git cat-file -t "$o" 2>/dev/null); [ "$t" = blob ] || continue
  git cat-file -p "$o" | sha256sum | grep -E 'c30aa2d6|260bf2c1|4a70b30f|afaf4b41' && echo "PII BLOB: $o"
done; echo "audit done"
```

Ожидаемый вывод — только `audit done`.

## Остаточный риск

Маскировка закрывает текст на изображении, но не отменяет того, что кадры снимались в живой
сессии. Значения, которые видны на очищенных кадрах (PKD 7311Z, период 11.2026, статус
Wysłany), подтверждены только для наблюдавшейся сессии 21.10.2026.
